# Animated cut v2

This version is pose-to-pose animation, not a still slideshow.

## What changed
- One locked identity plate for Ryu (white gi, red headband) and Ken (red gi, blonde hair)
- 17 sequential action keys generated from that plate
- Cross-dissolved motion between punches, kick, Hadoken growth, Shoryuken rise, clash, K.O.
- Same original 30s score
- YouTube 1920x1080 and TikTok 1080x1920, both 30.00s / 30fps

## Honesty
This session cannot call Grok Imagine Video 1.5 (no video API key in the sandbox). True limb-accurate fluid video needs image-to-video on those locked frames. The keys in `imagine_images/` are the correct first frames for that.
